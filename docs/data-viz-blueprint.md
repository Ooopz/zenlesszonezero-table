# 爬取数据可视化与练度提升分析蓝图

> 目标：让用户对「游戏内玩家练度」有全面认知（宏观全景），并能据此分析「自己该如何提升」（微观行动）。
> 本文盘点现有能力、指出未挖掘的数据维度，给出可视化蓝图与实施路线。

---

## 1. 数据资产盘点

### 1.1 爬取口径（2026-08 更新）

`workshop.json` 的样本定义已变更：

- **旧口径**：每个角色 × 每个影画档位（0-6）各取排行榜前 100 条**角色条目**。
- **新口径**：先按「角色 × 影画档位」取排行榜**全量**（实测每档上限 ≈298 去重 uid，offset≥300 为空；2026-08 起 `PER_RANK` 默认 300）的 **uid**，再抓取这些 uid 的**全部角色**。
- **uid 扩展已实测的边界**：`weapon_id`/`part_index` 为榜单子集/被忽略，`type` 变体返回空，uid 自增扫描不可行（uid 空间 10^7~1.5×10^9、无效 uid 也返回 code:0 data:null、命中率极低且易触发风控）——排行榜全量即当前可获取 uid 的最优路径。

新口径下的数据特性（全量流式验证，358,137 条）：

| 特性 | 数值 | 含义 |
|---|---|---|
| 总条目数 | 358,137 | 全量角色实例 |
| 玩家数（uid） | 25,898（旧 100/档）→ 预计 6-8 万（300/档全量） | 能进入「某角色某影画档排行」的玩家池 |
| 每玩家角色数 | 1 ~ 54（中位 13，p90 24） | **每个玩家拥有完整角色池** → 玩家级画像成为一等公民 |
| 每玩家有影画角色数 | 中位 6，最多 50 | 玩家池整体投入度高 |
| 每角色样本量 | 720 ~ 20,265（中位 5,568） | 热门角色样本充足，冷门角色分层统计需谨慎 |
| `rank` 影画分布 | 0 影 46.5% / 1 影 13.6% / 2 影 15.1% / 6 影 18.1% | **真实玩家池构成**（不再是爬取策略的均匀产物） |
| `level` | 100% 为 60 级 | 工坊展示对象均为满级，等级无区分度 |
| `relic_point` | 100% 为字符串（如 `"294.30"`），少量 `"0.00"` | 需 `Number()` 归一；0 值需甄别 |
| 音擎稀有度 | 100% 覆盖 | S/A 占比可聚合 |

> **定位**：这个玩家池 = 「每个角色练度排行的上榜者」。它比全服更强（为角色投入最多的人），比旧口径更真实（每个玩家的完整角色池，而非孤立角色条目）。**它是「高练度标杆池」——我的面板/评分与该池的百分位对比，是比「全服平均」更严苛、更有指导意义的对标。**

## 2. 现有可视化能力评估（统计视图 5 子面板）

| 子面板 | 已有图表 | 解决什么问题 |
|---|---|---|
| 角色面板 | 小提琴+箱线（玩家分布+推荐三档+我的）、直方图+密度+CDF+我的百分位、推荐三档范围条、perRole 密度散点 | 单角色「我 vs 玩家 vs 攻略」三维对标 |
| 角色配装 | 工坊实况 vs 方案推荐 Top 音擎/套装 + 差异分析 | 配装偏离诊断 |
| 驱动盘 | 方案推荐/全服使用/工坊真实三口径并列 + 词条组合/有效词条分布 | 驱动盘生态与毕业度 |
| 角色配队 | 组队引用统计 | 角色生态位 |
| 角色总览 | 达标热力图（我的玩家百分位）、共识度散点（玩家分化 vs 攻略分歧）、全局密度散点 | 我的角色池全局画像 |

**已有设计的正确之处**（后续延续）：
- 「我的值 / 玩家分布 / 推荐目标」三要素同图呈现——练度对标的核心叙事。
- 百分位作为跨属性通用语言（热力图按百分位上色），解决量纲不可比问题。
- 分布图全部基于同步时算好的 `hist`/分位/箱线要素，浏览器端零重计算。

**新口径带来的语义升级**：`panels` 分布现在描述的是「该角色上榜玩家池」——即每个角色的分布 = 为该角色投入最多的玩家群体。因此现有所有「玩家百分位」图表实际是**高练度标杆对标**，比「全服平均」更有指导意义（UI 需标注口径）。

**主要缺口**：
1. 数据层已提取评分/影画/技能/深渊/权重等字段（2026-08 起），但**聚合层尚未消费**（relicStats/rankLayers/playerProfiles/skillDist/abyssStats 都还没进 workshop-stats.json）；
2. `panelCorr`（属性相关性）已算好但前端零消费；
3. 缺少「结论输出」层——现有图都是描述性对标，没有「下一步做什么」的排序清单。

## 4. 练度全景可视化蓝图

设计原则：**三层叙事** —— 全局生态（一眼看懂）→ 单角色分布（玩家普遍水平）→ 我的对标（我处于哪、差在哪、先做什么）。

### 4.1 宏观层：玩家练度生态（新增「练度总览」子面板）

| 图 | 数据 | 说明 |
|---|---|---|
| 全角色练度评分分布（小提琴/山脊图） | relic_point 按角色聚合分布 + 我的值 | 「高练度玩家池普遍什么水平」的第一眼答案；每角色一行，色 = 我的百分位 |
| 影画档位金字塔（每角色堆叠条） | rank 0-6 占比 | 玩家投入分布：哪些角色人人 6 影（人权卡）、哪些 0 影居多；**新口径下此图有效** |
| 玩家级总览散点 | uid 聚合：X=角色池大小、Y=平均评分、气泡=最高评分 | 玩家生态：休闲/中度/重度玩家聚类，我的位置一目了然 |
| 双队完成度矩阵 | uid 聚合：是否有 6 个高评分角色、角色池内满级/满影/高分占比 | 高练度玩家「全池投入」vs 普通玩家「单队投入」的生态差异 |

| 深渊战绩分布 | `workshop-abyss.json` 聚合：层数/评级分布、评分 vs 层数散点 | 练度→实战验证：高评分是否真能打高层；「差多少练度才能上 X 层」 |
| 属性 trade-off 热力表 | panelCorr（数据已有，零同步成本） | 暴击率×暴伤 正/负相关一览，理解面板配比规律 |
| 音擎稀有度分布 | weapon.rarity | S/A 音擎普及率 |
| 角色共现网络（进阶） | uid 角色池共现 | 练 A 的玩家也练 B → 真实配队亲和性、角色生态位（替代/互补关系） |

### 4.2 微观层：我的对标与提升（增强现有「角色面板/角色总览」）

已有（保持）：小提琴三要素、分布形态+我的 P、三档范围条、达标热力图。

新增（结论输出）：
1. **练度评分仪表盘/条形**：我的角色评分 → 玩家池百分位（沿用 approxPercentile），一眼「我的角色池整体水平」。
2. **提升优先级清单（核心新增）**：按角色 × 属性计算 `缺口 = 推荐中档 − 我的值`、`落后度 = 50 − 我的百分位`，加权排序输出「先做什么」：
   - 例：暴击率 P12 且未达中档 → 4 号位驱动盘换暴击率主词条收益最大；
   - 按影画/音擎/驱动盘/面板四类归因，标注「换装备可解」vs「抽卡可解」。
3. **驱动盘级诊断**：我的每块盘 → 该盘有效词条数分布（effDist）+ 主词条正确率 → 标红最该替换的 1-2 块盘。
4. **同段位配装学习**：玩家池按评分分 P25/P50/P75 段，展示高段玩家音擎/套装/456 主词条偏好 vs 我的差异 → 具体到「换成什么」。
5. **技能对标（2026-08 新数据）**：我的 6 技能等级 vs 该角色玩家池技能分布 → 「哪几个技能该点」（技能点投入建议）。
6. **深渊对标（2026-08 新数据）**：我的深渊层数/评级 vs 玩家池分布 + 同练度玩家的实战配队 → 「我的练度能打到哪、卡在哪一层」。
7. **影画对标（新口径特有）**：我的角色影画档 vs 该角色玩家池影画分布 → 「缺的档位是否值得补」（结合按影画分层的面板差距图，量化影画收益）。

### 4.3 可视化技术要点

- 百分位是跨属性唯一可比语言，所有新增图沿用；分布一律同步时算好（hist/分位），浏览器零重计算。
- 新增聚合全部写入 `workshop-stats.json`（保持 1-2 MB 内），前端新增一个「练度总览」子面板即可（`recommend.js` 的 `TABS` + `PANEL_RENDERERS` 各加一项，图表函数加在 `charts.js`）。
- 数据口径标注：所有工坊分布图注明「上榜玩家池样本（高练度标杆）」，避免误读为全服分布。

## 5. 提升分析的产品化设计

「帮我分析如何提升」的本质是把对标结果转成**有序行动**：

```
我的面板 → 百分位对标 → 缺口计算（推荐中档 − 我的）
                          ↓
          归因分类（装备可解 / 抽卡可解 / 养成耗时）
                          ↓
          按 缺口大小 × 角色价值（出场率/是否主 C）排序
                          ↓
          输出：提升清单（每项：角色、属性、当前→目标、手段、预期收益）
```

具体产出物建议：
1. **角色级**：每角色一张「短板雷达/条形」（我的百分位 vs P50/P90），附 1-2 条机器生成建议（规则引擎即可，无需 LLM）。
2. **池级**：全角色「提升回报排行」——把有限的树脂/唱片时间投到缺口最大、价值最高的角色上。
3. **驱动盘级**：换盘建议（哪块盘有效词条垫底、主词条错误、与组合 Top 差距）。
4. **策略级**：影画/音擎抽取建议（我的角色影画档位 vs 玩家池中位数，缺档是否值得补——用按影画分层的面板差距量化收益）。

## 7. 风险与注意事项

- **样本偏差**：新口径 = 「每个角色各影画档排行全量（每档 ~300）的 uid」的完整角色池（预计 6-8 万玩家），是**高练度标杆池**，不是全服随机样本；所有分布/百分位对标都强于全服平均，UI 必须标注口径。同时它也不是旧口径的「每档强制均匀」——0 影角色占比 46.5% 反映真实玩家池构成。
- **rank 分层样本量**：每角色每影画档 ≈ 300 条上榜 uid（其角色条目数 = 该 uid 池中该角色出现次数），分层统计波动较大，需最小样本阈值（如 ≥30）并标注。
- **relic_point 口径**：字符串类型需归一；`"0.00"` 条目可能是未带驱动盘或 2025 源缺失，聚合前与 `equips` 长度交叉验证。
- **panelCorr 解读**：相关性是玩家配装取舍的结果而非因果，仅作 trade-off 参考。
- **性能红线**：浏览器端永远只加载 `workshop-stats.json`（≤2 MB）；一切新聚合在同步脚本完成（358k 条全量流式重算一次约 1-2 分钟，可接受）。
- **测试**：新增聚合函数需配套 `test/workshopStats.test.js` 用例，并加入 package.json 测试脚本。
