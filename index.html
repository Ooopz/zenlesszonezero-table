使用说明

推荐用法：运行 npm start 启动本地服务器（自动打开页面），然后点 header 的 「同步数据」下拉菜单一键更新：
① 更新数据库 —— 角色/音擎/驱动盘/邦布的基础数据；
② 更新我的角色 —— 拉取你账号的真实角色（首次需粘贴 cookie，之后自动缓存到 data/.cookie.json）；
③ 更新推荐方案 —— 米游社养成指南的推荐方案（每角色前 20 个：推荐面板、推荐音擎/驱动盘、4/5/6 号位主词条、副词条推荐）。

数据来源：所有数据存于 data/ 目录（library.json / characters.json），由本地服务器经 /api/data 提供，需 npm start 后才能访问页面。

目标设置：点卡片「目标」按钮，为角色一站式配置：目标属性值（百分比填整数，如暴击率 60 表示 60%）、推荐音擎、4/5/6 号位主词条、有效副词条（可一键从下方推荐方案应用）。卡片显示各项 「当前/目标」的达成率进度条与总体达成率。每个角色各自保存。

统计表格：点「统计表格」切换到一览视图，每个角色一行（角色/音擎/驱动盘/各属性值）， 属性值下方有小进度条显示该角色的达成率；再点「卡片视图」切回。表头/行可拖动排序。

副词条命中：「目标」弹窗的「有效副词条」区勾选视为有效的副词条属性；驱动盘词条旁标注 ×n（该词条强化次数，按 B 站 wiki 成长规则由词条数值推算），副词条命中次数 = 六个盘落在有效属性上的词条次数之和（每个词条本身算 1，每强化一次再 +1）。

最终面板数值：优先显示账号接口返回的真实值（和游戏内一致）；「计算明细」是用属性库基础值 + 装备推算的， 4 件套条件效果等未计入，可能与实际略有出入。

命令行方式（可选）：npm run sync:library / npm run sync:characters / npm run sync:plans，效果与网页一键更新相同 （sync:plans 可加 -- --account 只同步账号已练角色）。
