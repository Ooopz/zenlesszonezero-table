使用说明

推荐用法：运行 npm start 启动本地服务器（自动打开页面），然后就能在网页上一键更新： 点「同步属性库」更新基础数据，「同步我的角色」拉取你账号的真实角色（首次需粘贴 cookie，之后自动缓存到 .cookie.json）。

数据来源：所有数据存于 data/ 目录（library.json / characters.json），由本地服务器经 /api/data 提供，需 npm start 后才能访问页面。

目标设置：卡片头部「目标」按钮为该角色单独填写目标属性值（百分比填整数，如暴击率 60 表示 60%）， 卡片显示各项「当前/目标」的达成率进度条与总体达成率。每个角色各自保存。

统计表格：点「统计表格」切换到一览视图，每个角色一行（角色/音擎/驱动盘/各属性值）， 属性值下方有小进度条显示该角色的达成率；再点「卡片视图」切回。表头/行可拖动排序。

副词条命中：卡片头部「有效」按钮为该角色勾选视为有效的副词条属性； 驱动盘词条旁标注 ×n（该词条强化次数，按 B 站 wiki 成长规则由词条数值推算）， 副词条命中次数 = 六个盘落在有效属性上的词条次数之和（每个词条本身算 1，每强化一次再 +1）。

最终面板数值：优先显示账号接口返回的真实值（和游戏内一致）；「计算明细」是用属性库基础值 + 装备推算的， 4 件套条件效果等未计入，可能与实际略有出入。

命令行方式（可选）：npm run sync:library / npm run sync:characters，效果与网页一键更新相同。

目标属性设置 ·

为该角色填写目标属性值（留空 = 不考核）。百分比属性填整数（如暴击率填 60 表示 60%），其余填实际数值。每个角色单独保存。

有效副词条设置 ·

勾选该角色视为「有效」的副词条属性。副词条命中次数 = 六个盘落在有效属性上的词条次数之和（每个词条本身算 1，每强化一次再 +1）。
